# 音乐驱动的下落速度与停顿

- 状态：实现中（001–006 自动/浏览器完成，待用户真实曲 sign-off）
- 日期：2026-10-28
- 相关文档：`CONTEXT.md`、`docs/adr/0003-music-driven-fall-speed.md`
- 范围：音符驱动 + 网格驱动；浏览器预览/导出与 CLI 共用同一份 `Chart`
- 不在本 spec 内：默认原曲/手动切玻璃、玻璃音色重做（工作区已有未提交改动，单独提交）

## 1. 问题陈述

现在只有「什么时候撞」跟音乐：撞击时刻来自音符起音或拍网格。**「掉多快」是一个全局常量 V**（滑杆 260–900），BPM、能量、音符时值都不参与。

结果是：

- 快歌/慢歌、强段/弱段、密集段/长音休止，板子和相机都以同一个速度下滚；只有板子的疏密和撞击特效在变。
- 长音/休止仍然匀速下落，没有「音乐停下来、球也慢下来」的感觉。
- 弹跳高度虽然吃 `power`，但强弱对比不够；强拍和弱拍的滞空、停顿感差不多。
- 用户看到的是「球在撞击线附近弹、背景匀速滚动」，整体运动与音乐关系弱。

同步在这个项目里不能只等于「撞击时刻对齐」；球的速度、加速/减速、停顿和弹跳也必须跟音乐表情对应，否则画面仍然像一台匀速机器。

## 2. 方案概述

把纵向速度从常量改成**每段可变的 V**，再进入原有的闭式抛物线：

```
V = 基础速度
  × BPM 因子
  × 活跃度因子（谱通量 + 音符力度）
  × 长段落因子
  （全部按“变化幅度”缩放，再做 EMA 平滑与上下限夹取）

Δy = V · Δt
g 仍由本段 h / Δt 反解
```

关键性质不变：`s=0` 严格落在板 y，`s=Δt` 严格落在下一块板；`g` 与 `h` 自洽；相机仍是拍点 y 的分段线性弦；横向烘焙不受影响。

活跃度取两路：

- **谱通量包络**：取每段后 75% 的均值，按全曲 p90 归一化。它抓段落、长音、休止的「呼吸」。
- **音符力度**：音符驱动的 board power（amplitude/和弦规模/时值）或网格驱动的拍强度。它抓单音/单拍的强弱。

长音/休止**只减速，不硬停**：V 降低，球仍连续下落，下一拍仍严格落板；不会引入假板或打断运动模型。

弹跳强弱同样融合两路：`w` 由音符力度与音频活跃度共同决定；V 变化又改变 `Δy`，强段/密集段自然弹得更高、滞空更长。

## 3. 用户故事

### 速度

- **US-01** 快歌整体比慢歌滚得快：BPM 高的曲目在相同活跃度下 V 更大；BPM 低的曲目更慢。撞击时刻不变。
- **US-02** 活跃段比安静段快：响/密集段落的 V 高于弱/稀疏段落；V 与「谱通量 + 音符力度」的活跃度正相关。
- **US-03** 长音/休止减速：原始长音/休止间隔（split 成 ghost 之前）明显大于中位段时，V 降低；球仍在动，下一块板仍严格落上，不出现硬停或假板。
- **US-04** 变化幅度 0% 回到旧观感：V 在整个曲目恒定，`h = Δy/3`，无倾角、无特殊板；原有基线不变。
- **US-05** 变化幅度 100% 时速度/停顿反差最大；默认 70% 为中等（有效 V 约 0.6–1.6× 基础速度）。
- **US-06** 速度变化是平滑的：V 经过 EMA 平滑，相邻段不会出现肉眼可见的速度突跳；相机不顿挫。
- **US-07** 下落速度滑杆仍是基础速度：用户调 260–900 会整体缩放，但音乐跟随的相对比例不变。
- **US-08** 音符驱动与网格驱动使用同一套速度映射；`变化幅度=0` 时网格的旧视觉基线仍可复现。

### 停顿与弹跳

- **US-09** 强拍/强音弹得更高、滞空更长；弱拍/弱音更低；板宽与撞击强度同步变化。
- **US-10** 长音/休止的 V 降低带来「慢下来」的停顿感，但球不会停在板上；下一个起音仍准时落板。
- **US-11** 音频活跃度参与弹跳强弱：同一音符力度下，实际音频更活跃的段落弹得更高；不会只依赖模型 amplitude。
- **US-12** 弹跳高度不突破现有几何/屏幕/`0.9Δy` 上界；不产生 NaN 或板子互相穿插。

### 正确性与范围

- **US-13** 所有落点仍然精确：每个段末球 y 严格等于板 y，x 严格等于 `x1`；`g` 与 `h` 自洽；全时段无 NaN。
- **US-14** 相机锚点与横向烘焙不变：撞击帧球仍停在屏幕 58% 线；横向轮廓、倾角、特殊板逻辑不被速度映射改变。
- **US-15** 浏览器预览、浏览器导出、CLI 出片共用同一个 `Chart`，速度映射结果一致。
- **US-16** 不新增 FFT/音频分析开销：活跃度复用现有 `AnalysisResult.envelope` 与 board power；chart 构建仍是线性复杂度。
- **US-17** 界面语义清楚：滑杆叫「基础速度」；「变化幅度」的说明包含「速度与弹跳跟随音乐的强度」；不新增开关。

## 4. 已定决策

| 决策 | 结论 | 理由 |
|---|---|---|
| 速度公式 | `V = 基础速度 × BPM 因子 × 活跃度因子 × 长段落因子` | BPM 定整体快慢，活跃度做段落内加减速 |
| BPM 因子 | `1 + drama·(clamp(BPM/120, 0.7, 1.5) − 1)` | 快歌快滚、慢歌慢滚；限制极端 BPM |
| 活跃度 | 谱通量段落后 75% 均值（全曲 p90 归一化）与 board power 融合，0.6/0.4 | 包络抓段落/休止，power 抓单音强弱 |
| 长段落因子 | 长音/休止额外降低 V（`gap` 越大降得越多，封顶 30%·drama；`gap` = 距下一个真实板的原始间隔） | 用户选择“减速”而不是硬停；长休止会被 split 成 ghost，不能只看单段 dt |
| 平滑 | V 做 EMA（约 0.55 上一段 / 0.45 当前段），再做上下限夹取 | 避免相机速度突跳 |
| 上限/下限 | 基础速度 × `[1−0.55·drama, 1+0.9·drama]` | 默认 70% 约 0.615–1.63×；100% 约 0.45–1.9× |
| 停顿 | 只减速，不在板上硬停 | 保持连续下落、严格落点与现有相机模型 |
| 弹跳 | `w` 融合音符力度 + 音频活跃度；`h = Δy·bounceRatio(w, drama)`；适度扩大强弱区间 | 强段/强音更高，弱段/长音更低 |
| 控件 | 「下落速度」= 基础速度；「变化幅度」= 跟随强度；不新增开关 | 复用现有 UI；0% 是逃生舱 |
| 范围 | 音符驱动 + 网格驱动统一应用 | 用户要求整体下落动画跟音乐；0% 可回退旧网格观感 |
| 相机 | 不跟随球，仍用拍点 y 的分段线性弦 | 撞击帧锚点、seek 一致性与现有架构不变 |
| 落点 | 仍用闭式抛物线，`Δy = V·Δt`，`g` 由 `h/Δt` 反解 | 速度变化不影响落点精确性 |

## 5. 测试决策

### 接缝

优先复用 `buildChart` 作为主测试面，新增少量纯函数便于单测：

1. **`activityAt(analysis, t0, t1, p90)`**（新增纯函数）
   返回 0..1 的谱通量活跃度。空包络返回 0.5；p90 为 0 时回退 1。
2. **`combineActivity(envAct, wBase)`**（新增纯函数）
   按 0.6/0.4 融合谱通量与音符力度。
3. **`longFactorFor(gap, drama)`**（新增纯函数）
   按「距下一个真实板的原始间隔」返回长段落减速因子；drama=0 恒为 1。
4. **`speedFor(baseV, bpm, activity, drama, longFactor=1)`**（新增纯函数）
   返回本段未平滑的 V；包含 BPM、活跃度、长段落与上下限夹取。
5. **`buildChart(analysis, opts) -> Chart`**（现有接缝）
   段速度 = `seg.dy / (seg.t1 - seg.t0)`；主断言落在 Chart 上：落点、g/h 自洽、V 相关性、长段减速、平滑、`drama=0` 基线。
6. **`scripts/verify.mts` / `scripts/verify-note.mts` / `scripts/verify-speed.mts`**（现有与新增回归）
   继续跑 5 个鼓组/钢琴用例；新增速度映射断言。
7. **浏览器视觉检查**
   真实钢琴/表达性钢琴：密集段明显更快、长音/休止明显减速、强音弹跳更高；`drama` 0/70/100 对比。最终由用户 sign-off。

### 测试用例与断言

**A. 速度映射（Node）**

- `drama=0`：所有段的 `dy/dt` 相等（误差 ≤1e-9），且等于基础速度；`verify` 的 `h=Δy/3`、无倾角、无特殊板继续通过。
- 活跃度相关：表达性钢琴 fixture 上，段 V 与该段 `activity` 的 Spearman ≥0.5。
- 长段落减速：原始间隔 ≥2s 的 ghost 段（按距下一个真实板的间隔）平均 V 低于全曲平均 V 至少 10%（`drama=0.7`）。
- BPM 因子：用同一份 envelope/power 构造 60/120/180 BPM 三个假 `AnalysisResult`，60 与 180 的 V 比值 ≥1.3（`drama=0.7`）。
- 夹取：所有 V 在 `[base·(1−0.55·drama), base·(1+0.9·drama)]` 内。
- 平滑：相邻段 V 比值不超过阈值（初始 ≤1.4；若真实素材需要更平滑，调 EMA 而不是放宽阈值）。
- `drama` 单调：V 的方差 `drama=0 < 0.5 < 1`；`drama=0` 方差为 0。
- 网格 + 音符都覆盖：至少一组鼓组 fixture 和一组音符 fixture 跑同一组断言。

**B. 弹跳与停顿（Node）**

- 强弱对比：表达性钢琴强弱段，强段平均 h / 弱段平均 h ≥1.3（当前基线约 2.1，留余量）。
- 长段：长音/休止段平均 h 低于全曲平均 h；球仍连续，无非 ghost 假板。
- 上界：所有 h 通过 `clampBounce` 的现有上界；无 NaN、无板穿插；`maxTilt`、`maxOverhang` 与现有 `checkChart` 一致。

**C. 回归（Node）**

- `npm run verify` 5/5：拍点、落点、g/h、顶点、倾角、overhang、NaN 全通过。
- `npm run verify:note` 24/24：事件对齐、密集合并、静音段、力度、音高、玻璃时刻/音高、自动判定、起音精修。
- `npm run verify:speed`：活跃度相关、BPM 因子、长段减速、平滑/夹取、`drama=0`、网格与音符双模式。
- `drama=0` 的 Chart 与现有基线一致（V 恒定、h=Δy/3、无倾角/特殊板）。
- 同输入同 seed 的 Chart 完全相等（速度映射必须确定性）。

**D. 浏览器/视觉（人工）**

- 表达性钢琴：密集段滚速明显高于长音/休止段；长音段球明显减速但不硬停；强音弹跳/滞空高于弱音。
- `变化幅度` 0/70/100：0 回到旧匀速观感；70 中等；100 反差最大。
- 网格歌曲：默认视觉有速度起伏；把变化幅度拉到 0 能回到旧观感。
- 真实钢琴（本地 `fixtures/real/`）：用户最终确认「速度、停顿、弹跳」三项都跟音乐。

## 6. 明确不做

- 不在板上硬停、不新增「停留 + 下落」运动模型或相机模式。
- 不把相机改成跟随球；撞击帧仍锚定 58% 线。
- 不改横向轮廓、倾角、特殊板、玻璃音色、音轨切换（这些是其他改动）。
- 不新增响度/RMS 包络；只复用现有谱通量包络与 board power。
- 不新增 UI 开关；复用「下落速度」与「变化幅度」。
- 不改撞击时刻、板子生成、自动判定、起音精修。
- 不做逐曲手动速度校准（基础速度滑杆之外）。
- 不引入新依赖。

## 7. 补充说明

- **初始参数（可调，但语义锁定）**：
  - `tempo = 1 + drama·(clamp(bpm/120, 0.7, 1.5) − 1)`
  - `activity = 0.6·envAct + 0.4·clamp(wBase, 0, 1)`
  - `actFactor = 1 + drama·0.5·(2·activity − 1)`
  - `longFactor = 1 − drama·0.3·clamp((gap − 0.8)/2.5, 0, 1)`，`gap` = 距下一个真实板的原始间隔
  - `rawV = clamp(baseV·tempo·actFactor·longFactor, baseV·(1−0.55·drama), baseV·(1+0.9·drama))`
  - `v = i===0 ? rawV : 0.55·prevV + 0.45·rawV`
  - `w = clamp(wBase + drama·0.25·(envAct − 0.5), 0, 1)`
  - `envAct = mean(env[t0+0.25·dt .. t1]) / p90(env)`，空包络 0.5，p90=0 时用 1。
- **实现位置**：`src/chart/build.ts` 的段循环里计算；`activityAt`/`speedFor` 可以放在同文件或 `src/chart/speed.ts`，保持纯函数。倾角公式里的 `V` 改用本段平滑后的 `v`；`bakeReflectionXs` 继续用 `seg.dy/dt`。
- **弹跳区间**：已把 `bounceRatio` 的强弱区间从 `0.15..0.65` 扩到 `0.12..0.68`，`clampBounce` 继续兜底；`drama=0` 仍精确回到 `1/3`。
- **网格基线**：这次会改变默认 70% 下网格驱动的板距/高度指标；`drama=0` 是旧基线的唯一保证。验收不要求默认网格逐项不变，但落点/NaN/g 自洽必须继续通过。
- **预卷/幽灵板**：速度映射同样作用于预卷/长音细分；安静前奏会减速。`notesFromChart` 仍跳过 ghost，不产生假玻璃声。
- **性能**：活跃度只读现有 `envelope`，不新增 FFT；每段 O(段内帧数)，整体线性。
- **工作区状态**：默认原曲/手动切玻璃、玻璃音色重做是独立改动；本 spec 的实现/提交不要混入。
