# 玻璃珠表演轨迹原型（节拍优先）

- 状态：已采用（2026-10-28）；生产化见 `docs/specs/2026-10-28-bead-production.md`
- 日期：2026-10-28
- 相关文档：`CONTEXT.md`、`docs/adr/0005-bead-performance-trajectory.md`
- 范围：真实钢琴 15–20 秒段；新旧两版 mp4 对比；**不改变生产默认**
- 不在本 spec 内：生产 UI/开关、全曲、MDF 下落速度、默认原曲/玻璃音色、bubble Worker（工作区已有未提交改动，独立处理）

## 1. 问题陈述

现在的运动是运动学的：相机跟着拍点 y 的弦线，球被钉在屏幕 58% 附近上下弹，真正向下滚的是板子和背景；球没有落到板子上接触、滚动，板子只是撞击触发器。

用户要的是玻璃珠：**从上方掉下来 → 撞到一块玻璃板 → 沿板向下滚 → 掉出板边 → 按节奏撞到另一侧的板 → 反向滚 → 不断左右交替**。这在视觉上必须能看出「球在往下掉」「球贴着板滚」「板子从侧面出现」，而不是「背景匀速滚动」。

同时项目的核心承诺不能丢：撞击时刻必须和音符/节拍同步。自由物理模拟的撞击时刻是涌现的，不能保证对拍；因此本轮先做一个**节拍优先、物理为表演**的原型，用真实钢琴片段和现有运动做对比，确认观感后再谈生产替换。

## 2. 方案概述

先做一个独立 spike，不改生产默认：

```
真实钢琴 15–20s 片段
  → 现有音符/节拍事件（time、power、pitch、duration）
  → 两套渲染
       A. 当前运动：现有 buildChart/draw（弦线相机、竖直弹跳）
       B. 玻璃珠原型：滚动段 + 掉落段 + 慢跟随相机 + 左右交替板 + 板子入场
  → out/bead-old.mp4 / out/bead-new.mp4（同一素材、同一撞击点、同一音频）
```

玻璃珠路径在两次撞击之间分两段：

- **滚动段**：从本轮撞击点（板的外侧高点）沿板滚向中心低点；滚动时长由力度/时值决定，原始范围 0.45–0.75s（短间隔夹到 Δt−0.45s），球内标记可见地旋转。
- **掉落段**：从板的内侧低点离开，按重力/抛物线落到下一块板的外侧高点；下一块板在相反侧，下落段填满剩余到下一个拍点的时间。

撞击时刻仍是硬约束：每段终点在下一个音符/拍点，绝不靠自由物理漂移。相机慢跟随：滚动段相机不动，掉落段相机先向下走，球从 58% 上方可见地落入下一块板；撞击帧回到 58%。板子严格左右交替，并在下落段从对应侧提前滑入，撞击前到位。音高只影响板高/颜色/宽度与玻璃音高，不决定左右。

## 3. 用户故事

### 运动与节奏

- **US-01** 原型中每个撞击点都精确对应输入音符/拍点：撞击帧与音符时间的误差 ≤1 帧（60fps），不允许自由物理造成的累积漂移。
- **US-02** 每次撞击的左右严格交替：左→右→左→右；侧别不受音高影响。
- **US-03** 撞击点在板的外侧高点；球沿板向中心低点滚动；滚动方向与下一块板相反，球内标记按弧长/半径旋转。
- **US-04** 球滚到板的内侧低点后离开板边，在重力下抛物线落到下一块板的外侧高点；掉落段终点严格是下一个撞击时刻。
- **US-05** 滚动时长跟随力度/时值：强拍/长音滚得更久、板更长；弱拍/短音滚得更快。滚动段原始范围 0.45–0.75s，掉落段填满剩余时间且 ≥0.45s。
- **US-06** 下一块板在下落段从对应侧滑入，撞击前已到位；不会出现球撞在仍在运动的板上。

### 相机与视觉

- **US-07** 相机慢跟随：段内球在屏幕上真实下落，能看出坠落；撞击帧球精确回到屏幕 58%。
- **US-08** 球是玻璃珠质感：有可见的滚动（球内偏心内含物按弧长/半径旋转）、边缘高光、接触闪光和拖尾；板子是玻璃板。
- **US-09** 板高/颜色/宽度随音高变化；玻璃音高继续跟旋律；左右仍严格交替。
- **US-10** 画面不出现上一轮运动的「球被钉在 58%、只有背景滚」的错觉。

### 原型交付

- **US-11** 输出同一 15–20 秒真实钢琴片段的 `bead-old.mp4` 与 `bead-new.mp4`；两版使用同一组音符/撞击点、同一音频、同一分辨率/帧率，方便直接对比。
- **US-12** 原型可重复渲染：同一输入/seed 输出一致；不依赖在线模型或网络。
- **US-13** 原型不改变生产默认、不修改现有 MDF/音频/Worker 的未提交改动；旧运动保留用于对比/回退。
- **US-14** 用户观看两版后给出结论：采用玻璃珠原型 / 继续调 / 放弃；采用后才拆生产任务。（2026-10-28：用户确认采用，进入生产 spec/tickets）

## 4. 已定决策

| 决策 | 结论 | 理由 |
|---|---|---|
| 节拍 vs 物理 | 节拍优先，物理为表演 | 撞击必须对拍；滚动/掉落是反解/烘焙的表演 |
| 相机 | 球真实下落，相机慢跟随，撞击帧 58% | 用户要“掉下来”的坠落感 |
| 左右 | 严格左右交替 | 形成清楚的玻璃珠之字形 |
| 撞击点 | 外侧高点；滚向中心低点；掉边到下一侧外侧高点 | 板是向内倾斜的玻璃坡道 |
| 滚动时长 | 力度/时值决定，固定 0.45–0.75s | 强拍/长音更久，弱拍/短音更快；慢曲需要足够时间看出滚动 |
| 板子入场 | 下落段从对应侧提前滑入，撞击前到位 | 用户要“板子出现”，但撞击时板必须稳定 |
| 音高 | 只影响板高/颜色/宽度与玻璃音高 | 左右由交替决定，不让音高破坏之字形 |
| 落地方式 | 先做真实钢琴 15–20s 新旧两版 mp4 | 先验证观感，不直接替换生产默认 |
| 撞击密度 | 慢曲原型 `minGap=0.7s`，保留真实音符子集 | 撞击太密时滚动段只剩 0.2–0.3s，视觉像滑过 |
| 滚动线索 | 球内偏心深色内含物 + 弧线按弧长/半径旋转 | 球体径向对称，仅靠位移读不出滚动 |
| 生产范围 | 本轮只做原型 | 旧弦线/弹跳运动保留对比/回退 |
| 物理引擎 | 不引入自由物理模拟；用确定性的滚动+抛物线烘焙 | 保证可 seek、可导出、对拍 |

## 5. 测试决策

### 接缝

1. **音符/撞击点输入**
   使用现有 note-driven 数据（time/power/pitch/duration）；真实片段通过现有 Worker/分析得到并缓存为本地 JSON，避免每次渲染重新推理。
2. **`buildBeadChoreography(notes, opts) -> BeadPath`**（新增纯函数，spike 内）
   输出每段的滚动、掉落、板几何、板入场、相机关键点。Node 可单测。
3. **`drawBead(ctx, path, t)`**（spike 渲染器）
   玻璃珠、玻璃板、板的入场、相机；与旧 `draw()` 输出两版。
4. **现有 `buildChart`/`draw`**
   旧版对比基线；不改生产代码。
5. **spike 渲染脚本**
   真实片段 + 旧/新两版 mp4；ffmpeg 封装；可重复。

### 测试用例与断言

**A. 路径正确性（Node，纯函数）**

- 每个段的 `impactT` 严格等于输入音符/拍点（误差 ≤1e-6）。
- 侧别序列严格 L/R 交替；第一块板的初始侧固定、可复现。
- 滚动段：起点是板外侧高点、终点是板内侧低点；滚动时长原始范围 0.45–0.75s，且始终 ≤Δt−0.45s；随 power/duration 单调。
- 掉落段：起点是滚动终点、终点是下一块板外侧高点；终点时刻 = 下一个 impactT；掉落段 ≥0.45s，无 NaN、无穿板。
- 相机：在每个 impactT 处 `camera(t)` 使球位于屏幕 58%；滚动段相机不动，掉落段相机单调向下、无突跳，球在中段落于 58% 上方。
- 板入场：入场开始不早于上一段滚动结束，入场结束 < impactT；撞击时板已在最终位置。
- 同输入/同 seed 输出完全一致。

**B. 渲染/视觉（人工 mp4）**

- `bead-new-preview.mp4` 为 8 秒；`bead-new.mp4` 为完整 18 秒。
- 新版中能看出：球从上方掉落 → 撞板 → 沿板滚（内含物可见转动）→ 掉边 → 撞另一侧板；左右严格交替。
- 撞击帧与音频中的音符/玻璃敲击对齐；没有明显漂移。
- 下一块板从对应侧滑入，撞击前到位。
- 相机让球从上方真实落进板面，撞击帧回到 58%；球/板是玻璃质感。
- 与 `bead-old.mp4` 对比：新版不再像“球被钉住、背景滚”。

**C. 交付与边界**

- 两版 mp4 使用同一片段、同一音符/撞击点、同一音频、同分辨率/帧率。
- 原型脚本可重复运行；不联网、不调用 LLM；输出到 `out/`（不入库）。
- 不改生产默认；旧运动保留；不混入 MDF/音频/Worker 未提交改动。

### 完成定义

- A 的纯函数断言全部通过。
- B 的新旧两版 mp4 产出并由用户观看。
- 用户给出“采用 / 继续调 / 放弃”的明确结论；采用后才进入生产 spec/tickets。

## 6. 明确不做

- 不把玻璃珠运动接入生产默认、不加 UI 开关、不做全曲。
- 不引入自由物理引擎/实时物理模拟；不做时间弯曲。
- 不改 MDF 下落速度、默认原曲/玻璃音色、Worker 提取（工作区已有未提交改动）。
- 不重做玻璃音色/混音；原型沿用现有冲击声/音频。
- 不追求最终板子美术/粒子/音效；原型先验证运动、相机、板入场和节奏。
- 不改音符/拍点分析、onset 精修、自动判定。
- 不做多乐器/复杂碰撞（同时多球、板碎等）。
- 不把原型代码当作生产提交；通过验收后再决定是否复用/重写。

## 7. 补充说明

- **素材**：使用用户提供的 `006.夜的钢琴曲5 - 文武贝.mp3`（168.5s）截取 15–20 秒有音符的段落；片段和音符 JSON 放本地 `out/`/`fixtures/real/`，不入库。
- **音符来源**：优先复用现有 Worker 对片段提取的 basic-pitch 音符（time/pitch/amplitude），缓存为 JSON；原型渲染不再重新推理。原型不依赖模型在线状态。
- **旧版基线**：使用当前 `buildChart` + `draw`（含工作区里已有的 MDF 速度映射）和同一组 noteSource/音频；不做任何修改。
- **新版路径（初始参数，可调）**：
  - 板外侧高点 `x = ±sideX`，内侧低点 `x = ±innerX`，板是向内倾斜的玻璃坡道；撞击在外部高点。
  - `slideT = clamp(0.45 + 0.30·(0.65·power + 0.35·durNorm), 0.45, 0.75)`，并夹到 `Δt − 0.45`；掉落段 = Δt − slideT（≥0.45s）。慢曲原型用 `minGap=0.7s` 抽稀撞击，18s 片段 16 次撞击。
  - 掉落是重力抛物线：给定滚动终点、下一个外部高点、fallT，反解初速度/重力；终点严格对齐下一个 impactT。
  - 滚动可见化：球内深色内含物 + 弧线按滚动角旋转；左板顺时针、右板逆时针，空中保持角速度。
  - 相机：撞击点对准 58%；滚动段不动，掉落段相机先向下走（smoothstep），球从 58% 上方落进下一块板；不能破坏 seek/export 可复现性。
  - 板入场：在下落段的某个比例内从侧边滑入，结束早于 impactT；入场后板静止，撞击点稳定。
  - 音高：板高/宽度/颜色 + 玻璃音高；左右不受音高影响。
- **可复现性**：路径烘焙成关键帧表，渲染只按 t 求值；不使用每帧随机/当前时间。
- **工作区状态**：MDF、默认原曲/玻璃音色、basic-pitch Worker 三组未提交改动与本原型分离；原型不修改它们，提交也不混在一起。
- **原型通过后**：再决定生产 spec/tickets（新的运动/相机/板几何、与 MDF 速度/玻璃音轨的整合、回归与真实曲验收）。
