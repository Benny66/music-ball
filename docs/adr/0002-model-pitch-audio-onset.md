# 模型音符负责音高，音频 onset 负责时刻

钢琴独奏的 basic-pitch 转写会在重叠音/长音上把起点提前 60–80ms，并把长音谐波识别成额外音符；只信模型时板时间 p90 约 138ms，长音段还会出现假撞击。我们决定：模型继续提供音高与和弦分组，但每个音符的起点吸附到宽频谱通量 onset（±160ms）；窗口内没有起音的模型音符视为谐波/多检直接丢弃。

备选方案：只用模型（时刻 p90 差）、只用音频起音（没有音高/和弦）、按音程做谐波抑制（会误删低声部之上的真实旋律）。

## 后果

- 旋律音符数会减少；没有可检测起音的极弱音符会丢失。
- 玻璃音高与和弦板仍来自模型，撞击时刻来自音频，两者共用同一条 onset 时间轴。
- 该精修只在浏览器 basic-pitch 路径启用；Node 回归用真值音符，不经过精修。
