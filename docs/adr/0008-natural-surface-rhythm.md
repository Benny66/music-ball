# 音符驱动默认改为表面节奏 + 自然滚动

状态：accepted（2026-10-29）

背景：0006 之后音符歌用拍点玻璃珠，撞点按 0.7s 抽稀。真实钢琴验收发现三类问题：绝对 0.75s 在 108BPM 下是 1.5 拍，25 次里 12 次落半拍；改成每 2 拍又太慢；拍点玻璃珠的严格左右交替 + 板子滑入，也不符合用户要的「球自然落体、左右滚动跳动」。独立 MIR（Essentia.js，仅离线诊断）显示现有拍点在 20–30s、90–100s、150–160s 有漂移段；150–160s 还是三连音流动段，主拍网格表达不了。

决定：音符驱动默认改为「表面节奏选点 + 自然滚动」。

- 撞点候选是**音符板起音**，拍点只做节拍权重；1/3、2/3 细分位置权重 0.75，三连音/切分可被选中。
- 选点用 O(K·N) 区间 DP：目标密度 1.2 次/秒、最短间隔 0.5s、超过 1.8s 的空隙按最高分补点。
- 自然滚动：板提前存在、左右/中心自由、低通镜头 54%、首板前钉住镜头；撞击时刻严格等于选中的起音。
- 钢琴拍点追踪同时收紧（`highRatio<0.09` 时 DP 规整惩罚 1.5，并绕过全局锁相网格），整拍规律度 0.882→0.967。
- 网格/鼓组仍走 0006 的拍点玻璃珠；经典运动保留手动回退。

备选方案：直接采用 Essentia 拍点（AGPLv3，不能随应用分发）；继续用全局锁相网格（钢琴中位误差反而更大）；绝对 0.75s 自由选点（1.5 拍，用户已否）；连续物理弹跳（用户明确要滚动玻璃珠，不要弹跳）。

## 后果

- 新增 `src/chart/natural.ts`、`src/chart/salience.ts`、`src/render/natural.ts`；`Scene` 增加 `natural`，`motion` 增加 `natural`。
- 玻璃音轨改由 `notesFromNatural` 生成；预览、Node 导出、播放中音符升级都走同一场景。
- 旧拍点玻璃珠仍作为网格路径与构建失败回退，`verify:bead` 继续覆盖。
- 150–160s 与 Essentia 的选点仍有差异（Essentia 跟 0.36s 表面网格，自研跟音符起音），但自研撞击 87% 落在音符板 80ms 内，全曲中位差 17ms。
- 长前奏的球从首板上方落入；首板前镜头不追球，否则板子会被推出画面。
