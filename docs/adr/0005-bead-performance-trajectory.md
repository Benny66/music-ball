# 节拍优先的玻璃珠表演轨迹（先原型后生产）

状态：accepted（原型已采用；生产已接入，待全曲用户确认）

背景：当前运动是运动学的——相机跟着拍点 y 的弦线，球被钉在屏幕 58% 附近弹，板子只是撞击触发器，球没有落到板上接触/滑行。用户要的是玻璃珠：掉下来、撞到板、沿玻璃板向下滑、掉边、按节奏撞到另一侧的板，再反向滑，形成左右交替的之字形。

决定：撞击时刻仍严格来自音符/节拍（节拍优先）；在两次撞击之间烘焙一条「滑行段 + 掉落段」的表演路径，物理只负责看起来真，不产生自由模拟的时间漂移。相机慢跟随：撞击帧球仍精确回到屏幕 58%，滚动段相机不动，掉落段相机先向下走，让球从上方真实落进下一块板。板子严格左右交替；撞击点在外侧高点，球沿板滑向中心低点，掉边后落到下一侧板的外侧高点。下一块板在下落段从对应侧提前滑入，撞击前到位。滑行时长由力度/时值决定（强拍/长音滑得久，弱拍/短音滑得快），掉落段填满剩余时间。音高只影响板高/颜色/宽度与玻璃音高，不决定左右。

先做真实钢琴 15–20 秒的新旧两版原型（同一组撞击点），用户确认后才改生产默认；旧弦线/弹跳运动保留做对比与回退。

备选方案：自由物理模拟（撞击时刻涌现，可能漂移）；物理 + 节拍时间弯曲（局部变速）；只加滑动视觉（不换真实路径）。

## 后果

- 需要新的滑行/掉落路径、板子几何与入场动画、慢跟随相机；现有 `evalBall`/`evalCamera` 的抛物线-弦线模型不再足够。
- 拍点必须仍是硬约束：每段路径由「下一次撞击时刻」反解/烘焙，seek 与导出仍可复现。
- 原型不改生产默认，也不与工作区里 MDF/音频/Worker 的未提交改动混在一起；原型验收通过后再拆生产任务。

## 2026-10-28 第一次调参修订（滚动 + 慢速）

用户反馈：球在板上看起来是“滑过”而不是“滚动”，而且慢曲上滚动速度过快。

修订：
- 撞击抽稀：`minGap` 0.32s → 0.7s；18s 真实片段从 29 次撞击降到 16 次（中位 1.11s，最大 1.75s）。撞击时刻仍是真实音符起音的子集。
- 接触阶段改名“滚动段”：时长由 `Δt` 的 18–55% 改为固定 **0.55–1.0s**（按力度/时值插值），掉落段吃掉剩余时间且不少于 0.18s；首段滚动从约 0.27s 放慢到约 0.87s。
- 滚动可见化：球内加入偏心深色内含物与弧线，按“弧长 / 球半径”旋转；左板顺时针、右板逆时针，空中保持离开板时的角速度。仅靠球心位移不再作为滚动线索。
- 预览从 5s 改为 8s，让慢曲至少走完 5 次撞击；完整对比仍为 18s。
- 仍然节拍优先：撞击时刻、左右交替和 58% 相机约束不变。

## 2026-10-28 第二次调参修订（自由落体）

第一次把滚动段拉到 0.55–1.0s 后，短间隔只剩 0.18s 掉落，观感变成“横飞过去”。现改为滚动段原始 0.45–0.75s、最短掉落 0.45s；短间隔把滚动夹到 Δt−0.45，保证每段都有可见的自由落体。平均滚动约 0.56s、平均掉落约 0.59s。相机改为在掉落段先行向下，球从 58% 上方落进板面，避免“滞后相机把球拉回 58%”造成的上升感。

## 2026-10-28 采用结论

用户观看 8 秒预览与 18 秒新旧对比后确认采用玻璃珠方案（滚动 + 自由落体 + 板入场 + 撞击帧 58%）。生产范围先覆盖**音符驱动**（钢琴/轻音乐）；网格/鼓组保留经典运动。旧运动保留切换/回退，不与 MDF/音频/Worker 三组未提交改动混提。
