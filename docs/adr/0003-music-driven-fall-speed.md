# 滚动速度由 BPM 与音乐活跃度共同驱动

背景：纵向速度一直是常量 V，BPM、能量、音符时值都不参与；只有撞击时刻跟音乐，长音/休止仍匀速下落，整体下落动画与音乐关系很弱。我们决定：`V = 基础速度 × tempo(BPM) × 活跃度(谱通量 + 音符力度) × 长段落因子`，全部按现有“变化幅度”缩放；变化幅度 = 0 时回到恒定 V、统一弹跳的旧观感。长音/休止只减速，不做在板上硬停，保持连续下落与撞击时刻严格准确。

备选方案：只跟 BPM（长音/休止不会停顿）、只跟活跃度（跨曲速度不按 BPM 缩放）、在长音板上硬停（需要新的“停留 + 下落”运动模型和相机处理）。

## 后果

- 相机与板子的下滚速度随段落变化，需要对 V 做 EMA 平滑，避免镜头顿挫。
- 网格驱动的默认视觉指标会变化；`drama=0` 保留旧基线，现有落点/NaN 回归继续有效。
- V 仍由 `Δy = V · Δt` 进入闭式抛物线，落点精确性与横向烘焙不受影响。
- 长休止会被 `splitTooFar` 切成 ≤dtMax 的 ghost 段；长段落因子必须按原始「距下一个真实板」的间隔计算，不能只看拆分后的单段 dt。
