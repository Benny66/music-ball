# 弹跳强弱跟随

**Blocked by**: 003

**来源**: `docs/specs/2026-10-28-music-driven-fall.md`（US-09/11/12、测试 B）

## 目标

让弹跳高度同时跟随音符力度和音频活跃度：强段/强音弹得更高、滞空更长，弱段/长音更低；同时不突破现有几何/屏幕/`0.9Δy` 上界。

## 涉及层

- [ ] 逻辑层：`w = clamp(wBase + drama·0.25·(envAct − 0.5), 0, 1)`，用于板宽/厚度/accent/h；`bounceRatio` 的强弱区间适度扩大（初始 0.12..0.68），`drama=0` 仍精确回到 1/3
- [ ] UI层：无
- [ ] 测试：强/弱段 h 对比、长段 h、上界/NaN；现有力度映射用例必要时改为对 `w` 断言

## 验收标准

- 表达性钢琴强弱段：强段平均 h / 弱段平均 h ≥1.3；同一音符力度下，音频更活跃的段 h 更高。
- 长音/休止段平均 h 低于全曲平均 h；球仍连续。
- 所有 h 通过 `clampBounce` 上界；无 NaN、无板穿插；`maxTilt` / `maxOverhang` 与现有 `checkChart` 一致。
- `drama=0` 时 `h=Δy/3`；现有 `verify` 5/5、`verify:note` 24/24。
- 浏览器演示：强拍/强音明显弹得更高，弱音更低。
