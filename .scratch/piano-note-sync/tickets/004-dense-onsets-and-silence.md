# 密集起音与静音段

**Blocked by**: 003

**来源**: `docs/specs/2026-10-28-piano-note-sync.md`（US-07/US-09/US-10/US-11）

## 目标

快速跑动/装饰音按「合并、优先强起音」处理；长音/休止只保留幽灵板；预卷与合成板不再制造假撞击或假玻璃声。

## 涉及层

- [ ] 数据层：音符模式的前奏预卷不产生可撞击/可发声的板
- [ ] 逻辑层：`boardsFromNotes` 密集合并时选强起音；`mergeTooClose` 不推翻该选择；`splitTooFar` 在长间隔插 ghost
- [ ] UI层：ghost 不画板；音符模式前奏不出现半透明假板
- [ ] 测试：密集簇间隔 ≥125ms 且保留最强；静音段无非 ghost 板；`notesFromChart` 不产假事件

## 验收标准

- 全曲相邻非 ghost 板间隔 ≥125ms；每个 <125ms 的簇最多一块板，且其力度不低于簇内最强起音。
- 长音/休止段没有非 ghost 板；球仍连续运动（幽灵段），无 NaN。
- 在 2 秒前奏 fixture 中，0 到首音之间没有玻璃事件；`renderGlassTrack` 收到的事件全部对应真实板。
- 快速跑动段的可听强起音仍能在板上看到；视觉不出现 >8 板/秒。
- 现有 verify 5/5 通过。
