# 音高轮廓横向轨迹

**Blocked by**: 003

**来源**: `docs/specs/2026-10-28-piano-note-sync.md`（US-13/US-14）

## 目标

主导音高上行时球向右、下行时向左，音程越大横向位移越大；接近边界时回中，始终不出赛道。

## 涉及层

- [ ] 数据层：使用 001 的 `midi`
- [ ] 逻辑层：`buildTrackXs` 增加音符轮廓分支，替换随机扫掠；ghost 保持/插值；clamp；`dof` 语义保持
- [ ] UI层：无新控件
- [ ] 测试：上行/下行音阶方向、幅度 Spearman、边界、重复音高、确定性

## 验收标准

- 未触及边界的相邻板中，`Δpitch>0 → Δx>0`、`Δpitch<0 → Δx<0` 的符号一致率 ≥90%。
- `|Δpitch|` 与 `|Δx|` 的 Spearman ≥0.7；`|x|` 始终 ≤ 赛道半宽。
- 音高不变时横向基本静止（允许回中微调）；ghost 段不产生随机抖动。
- 默认 `dof` 下横向目标由音高轮廓决定；同 seed 输出一致。
- 现有 verify 5/5 通过。
