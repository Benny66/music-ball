# 待应用旋律：暂停 / seek / 播完应用

**Blocked by**: 003

**来源**: `docs/specs/2026-10-28-melody-worker.md`（US-08/09/10/11/12）

## 目标

提取完成时如果正在播放，不立即把网格图换成音符图；先缓存为“待应用旋律”，在暂停/seek/播完时应用。已暂停则立即应用；用户手动切“音符”时也立即应用。

## 涉及层

- [ ] 逻辑层：`pendingMelody` 状态与统一 `applyMelodyResult()`
- [ ] 逻辑层：完成时判断 `transport.playing`：播放中 → pending；暂停 → 立即应用
- [ ] 逻辑层：暂停、seek、`transport.onEnded`、手动 `rhythm='notes'` 都触发应用
- [ ] UI层：状态提示“音符驱动已就绪，暂停/跳转后应用”；应用后更新图表/状态
- [ ] 测试：播放中完成不跳图；暂停/seek/播完切换；已暂停立即；手动音符立即；换歌/取消清空 pending

## 验收标准

- 播放中完成：当前图表不变、播放位置连续；状态提示可见；暂停或 seek 后图表切到音符驱动。
- 已暂停时完成：立即应用，无需额外操作。
- 待应用期间手动切“节奏来源=音符”：立即应用。
- 待应用期间换歌/取消：旧 pending 清空，不应用。
- 应用后若当前是玻璃/混音，沿用现有逻辑重渲；预览与导出同一份结果。
- 现有回归通过；主线程无长阻塞。
