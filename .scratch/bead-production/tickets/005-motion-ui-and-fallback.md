# 运动选择 UI + 经典回退

**Blocked by**: 002, 003

**来源**: `docs/specs/2026-10-28-bead-production.md`（US-04/05、决策默认运动/回退）

## 目标

参数面板增加“运动：玻璃珠 / 经典”选择；音符驱动默认玻璃珠，网格显示经典且不可选玻璃珠；切换运动不打断播放/seek，经典可随时回退。

## 涉及层

- [ ] UI层：`index.html` 增加运动选择与说明；默认值按 `rhythmEffective` 自动设置。
- [ ] UI层：`src/main.ts` 增加 `motionChoice: 'auto'|'bead'|'classic'`；`rebuild()` 构建场景；切换时保留 `transport.time`、播放状态、音频模式。
- [ ] UI层：网格驱动时禁用玻璃珠选项并提示“网格驱动暂用经典运动”；音符驱动可切换。
- [ ] UI层：运动切换触发 `dirty`/玻璃缓存失效；不重建 transport、不重载音频文件。
- [ ] 测试：headless 浏览器加载真实钢琴，默认玻璃珠；切经典后画面变经典且时间不变；切回玻璃珠一致。
- [ ] 测试：网格歌曲选项禁用/提示；播放中切换不跳帧、不重启音频。
- [ ] 文档：参数说明更新；`README` 运动选择/回退说明（生产文档，不是原型文档）。
- [ ] 边界：不新增其他参数；不改 MDF/音频/Worker UI。

## 验收标准

- 音符驱动默认玻璃珠；选择经典后立即生效，`transport.time` 误差 <1 帧，播放不中断。
- 网格驱动运动选项为经典且禁用玻璃珠，提示可见。
- 切换运动后玻璃音轨按新场景重新生成；当前音频模式保持。
- 刷新/重新分析后默认选择符合当前节奏来源。
- 真实钢琴与网格歌曲均无控制台错误；typecheck/build 全绿。
